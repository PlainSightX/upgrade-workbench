# 本地 OpenAPI 客户端生成的行为要求

将完整 openapi-python-client 0.10.0 应用迁移到登记的新依赖环境。使用者提供本地 OpenAPI 文档与可选生成配置，应用解析文档，解析组件和接口之间的引用，渲染完整的模型、客户端、端点及项目元数据，并运行已有格式整理命令。

保持既有输入的含义：空配置仍可用，文档与配置控制名称和版本，模式字段的必填、可省略、可为空和原始名称应反映在生成物中，跨组件引用应指向正确的模型。生成的模型仍能按已有协议读写字典，生成的端点应保留路径组装与响应解析行为。原来拒绝的文档和不支持的主要版本仍需明确报错，不留下看似成功的项目。

只处理本地文件；验收不调用远端接口、不评估真实网络服务。不扩大到完整OpenAPI规范、认证协议、交互CLI、已有项目更新或自定义模板。只允许修改登记的应用Python文件；原有Jinja模板是只读上下文，检查、模板、依赖锁与合同不得修改。保留已有业务语义，使用兼容命名空间继续运行旧Pydantic不算原生新版迁移。
