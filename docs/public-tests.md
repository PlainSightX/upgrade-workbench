# 公开测试与历史测试的边界

公开候选保留全部产品源码，以及清单/补丁、AST、检索、请求、候选、账本、任务、报告和
服务层产品测试。默认运行 `pytest tests/unit`，无需本机历史布局、真实模型密钥或现有数据库。
测试没有因缺失文件自动跳过的分支。

私人工作包门禁、工作树登记、固定轮次 runner、旧部署脚本和精确历史复建测试不随公开版
分发。它们检验开发现场和原始重建，不是产品能力。`PUBLICATION.json` 列出排除的文件和
混合文件中的三个历史导出定义；Investigator 的全部产品消费与恢复测试仍保留。
官方工具输入测试直接消费产品 `codemod`；旧代理路由覆盖由产品 provider 测试保留。
历史 P2/P3 批次登记适配器及其身份/审阅拒绝测试也保留；它明确拒绝现代任务 schema。
现代任务使用普通 CLI 或服务，不能把旧实验调度器当作 P6 通用运行入口。

## 固定输入

公开默认测试使用 17 个案例目录、21 份 manifest，另有四文件 FlaskBB 导航片段。
它们都是静态产品测试输入，不是 17 组重新评估过的迁移成功案例。

多数输入保持原字节。少量公开派生输入用 `PUBLIC_FIXTURE.json` 记录原 manifest/hash、
移除成员和有界变化：

- Copier-r2 移除历史运行日志与只服务原复建的 revision 记录。
- FlaskBB 移除未消费的 docs/static/vendor 资产，保留 Python、模板与 ORM 测试夹具。
- 部分锁只移除本机编译命令注释，依赖行与哈希不变。

派生 manifest 有新的指纹，不能作为原实验输入或冒充旧成绩。
FlaskBB 探针初始化按逐项审查后的公开指纹另行绑定，原身份与伪身份拒绝仍保留。
四文件导航夹具仅验证真实应用工厂、扩展对象和跨文件消费链；不执行目标、不声称它是完整 HTTP 站点。
固定 csvsql 代表案例保持原身份，并经 Docker 独立复验。

原历史输入、完整日志和原 Git 历史保留在私有恢复材料中。公开精简不会重写历史分母或结果。
精简后的测试通过只证明公开集合的产品行为，不能和原完整私有单测数直接作功能增益比较。

## CI实际覆盖

自动push/PR作业运行产品单测、lint及锁文件不变检查，不发送模型请求。
手动 `workflow_dispatch` 的 `run_docker` 只允许默认分支运行：先复验Pydantic校准例，
再用首页csvsql固定补丁运行三环境最终六项检查，断言 `candidate_verified` 和
旧6/6、直升0/6、候选6/6。只上传三环境状态/计数的精选JSON；不上传包含runner绝对路径
的原比较报告、模型回复或运行日志。完整诊断留在该次CI执行现场，不进源码或发布附件。

这条CI复验的是已审查候选，不是自主生成、模型对照、历史故障恢复或成本收益重测。
配置已加入，本地同命令链有对应复验依据；GitHub尚未发布，远端Actions尚未执行。
语义风险机制的真实模型比较由独立记录拥有，不能从单测或固定补丁全绿推导收益。
